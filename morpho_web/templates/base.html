Morpho

Morpho helps students and hostel teams view availability, compare rooms, and track bed status from one simple dashboard.

Purpose

This portal is built to make hostel discovery clearer with location, pricing, reviews, rooms, and live vacancy indicators.

Current Scope

Authentication and API integration will be added later. The current version uses dummy hostel, room, and bed data for layout testing.
